# ADR 0004: Desktop Lifecycle Management, Secure Streaming Updater, and Type-Safe Frontend Bridge

## Status

Accepted

## Context

UniBootDesktop is a cross-platform desktop application built with Go, Wails v2, and Vue 3 / TypeScript. As a desktop application supporting multi-platform runtime environments (macOS, Windows, Linux) and self-updating capabilities, the application faces several critical architectural challenges:

1. **Context Lifecycle & Resource Safety:** Long-running background operations (such as asset downloads, network diagnostics, and update staging) must cleanly terminate when the GUI window is closed or the runtime is shutting down, preventing goroutine and socket leaks.
2. **Concurrency Protection:** User-triggered actions such as in-app GUI updates must be guarded against concurrent executions (e.g. repeated user clicks).
3. **Frontend-Backend Contract:** Interfacing through dynamic, unsafe global objects (`window as any`) bypasses TypeScript compile-time type checking and leads to fragile runtime errors.
4. **Update Security & Memory Efficiency:** Downloading release assets without cryptographic checksum verification exposes users to network tampering or truncated downloads. Furthermore, reading multi-megabyte archives entirely into memory (`os.ReadFile`) causes severe memory spikes on resource-constrained devices.
5. **Privilege Escalation Safety:** On macOS, updating an application residing in `/Applications` requires root privileges via AppleScript (`do shell script`). Using string concatenation with raw paths in AppleScript invites potential shell injection vulnerabilities.

## Decision

We have implemented an end-to-end architectural overhaul across the Go backend, update subsystem, and Vue frontend:

### 1. Robust Context Lifecycle & Concurrency Guards

- The `App` struct manages an internal `cancel context.CancelFunc` initialized via `context.WithCancel(ctx)` in `startup()`. On application `shutdown()`, `cancel()` is explicitly executed to cleanly tear down any in-flight asynchronous operations.
- The `PerformGuiUpdate()` method is protected by a mutex with `TryLock()`, immediately rejecting duplicate concurrent update requests with a clear error rather than blocking or corrupting staging state.

### 2. Type-Safe Frontend Bridge & Isolated Utilities

- All frontend calls in `App.vue`, `SettingsModal.vue`, `AboutModal.vue`, and `HelloPanel.vue` have been migrated from raw `(window as any).go` / `(window as any).runtime` to auto-generated type-safe bindings from `wailsjs/go/main/App` and `wailsjs/runtime/runtime`.
- Created `frontend/src/utils/wails.ts` providing `isWails()` and `isWailsRuntime()` detection helpers. This decouples the frontend from desktop-only runtime assumptions and guarantees graceful behavior when running standalone in web browsers during dev/test.
- Introduced Vitest automated unit testing in the frontend to continuously verify translations and bridge utilities.

### 3. Streaming Archive Extraction & SHA-256 Checksum Verification

- **Streaming I/O:** Added `archive.ExtractArchiveFromFile(path, destDir)` to `internal/archive`, streaming archive bytes directly from disk without allocating large byte slices in RAM. `DownloadWithProgress` now utilizes a 64KB `io.CopyBuffer` to maximize throughput.
- **Cryptographic Verification:** `PerformGuiUpdate` automatically locates and downloads `checksums.txt` from the release assets, computes the SHA-256 digest of the downloaded file, and verifies it against the official release manifest before extracting or staging. If checksums do not match, the payload is immediately deleted and the update aborted.

### 4. AppleScript Privilege Escalation Hardening

- Replaced inline string-interpolated AppleScript commands with a dedicated isolated helper script (`elevated_replace.sh`). The parent script passes `$TARGET` and `$STAGED` as cleanly quoted arguments, eliminating shell quoting ambiguities and injection risks.

## Consequences

### Positive

- **Memory Efficiency:** Large updates no longer cause multi-megabyte heap spikes, enabling seamless updates on lower-spec machines.
- **Security:** Strict SHA-256 verification guarantees binary authenticity prior to staging. Privilege escalation scripts are safely parameterized.
- **Type Safety & Maintainability:** Full TypeScript checking prevents bridge signature mismatches between Go and Vue.
- **Automated Verification:** Added unit test coverage for frontend utils, i18n interpolation, streaming archive extraction, and SHA-256 verification.

### Negative

- Minor build-time overhead in release pipelines to produce and sign `checksums.txt` (which was already generated by GoReleaser).
